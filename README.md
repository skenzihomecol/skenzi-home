# Skenzi Home — tienda inicial

## Incluye
- `index.html`: página principal.
- `categorias.html`: catálogo general.
- `hogar.html`, `deporte.html`, `tecnologia.html`, `industrial.html`, `juguetes.html`, `belleza.html`: páginas independientes.
- `novedades.html`, `contacto.html`, `carrito.html`.
- `css/estilos.css`: diseño responsive con identidad verde oliva, crema y carbón.
- `js/tienda.js`: menú desplegable, búsqueda básica, productos de ejemplo y carrito local.

## Publicación
Sube los archivos y carpetas a la raíz del repositorio de GitHub Pages, manteniendo la estructura. Abre `index.html` para revisar la página principal.

## Antes de vender
1. Sustituye los datos de ejemplo en `js/tienda.js` por productos, fotografías y precios confirmados.
2. Configura el número de WhatsApp comercial en la variable `numeroWhatsApp` dentro de `js/tienda.js` (indicativo de país y solo dígitos).
3. Confirma disponibilidad, envío y condiciones del pago contra entrega antes de aceptar cada pedido.

## Límites de esta versión
No incluye panel administrativo, base de datos, autenticación segura ni almacenamiento de pedidos en servidor. El carrito se guarda solo en el navegador del cliente. Para administrar productos, pedidos y contabilidad desde un panel privado se necesitará conectar un backend/base de datos con autenticación.
